# AI 籃球動作實驗室

上傳或拍攝籃球動作影片，用慢動作與逐格檢視拆解細節，在瀏覽器內做骨架分析，並與示範動作並排對照。

- 純靜態網頁，直接開 `index.html` 即可（建議經 localhost 或 HTTPS）。
- 影片及分析結果只存在你的瀏覽器（IndexedDB），不會上傳。骨架分析首次使用時需下載 MediaPipe 模型。
- 打開網頁即顯示一段側面拍攝的真人跳投示範片，右邊火柴人逐格複製片中動作；上載自己的影片後會自動分析並同樣複製。不用選動作類型：下方「動作拆解」自動找出影片中的跳投、上籃、轉身和運球，逐段逐個關鍵時刻寫出做得好和可改善的地方，並與示範片數值比較。
- 請從側面拍攝，與示範火柴人同一角度才可對照；球員向左時火柴人會自動反轉。

目前功能：上傳／拍攝、慢動作、逐格、時間點筆記；火柴人逐格複製動作；動作拆解；骨架分析（身體、手部、臉部、籃球、關節角度、關鍵時刻）；真人片與示範並排同步。

## 第三方素材
